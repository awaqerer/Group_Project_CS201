- велосипед → клас `Bike`, бо має номер і ціну
- електричний велосипед → клас `ElectricBike`, різновид велосипеда з іншою ціною
- станція → клас `Station`, бо має назву і велосипеди
- клієнт → клас `Client`, бо має ім'я і баланс
- номер → атрибут велосипеда
- ім'я, баланс → атрибути клієнта (рахунок = баланс)
- мережа → змінна з виручкою, потрібна лише сума
- місто, гривня, хвилина, адміністратор → не потрібні, бо не мають своїх даних

  Bike
- Знає: номер
- Вміє: повернути ціну хвилини (2 грн) і назву типу

ElectricBike (нащадок Bike)
- Знає: номер
- Вміє: повернути ціну хвилини (5 грн) і назву типу

Station
- Знає: назву, список велосипедів
- Вміє: додати, видати і порахувати велосипеди

Client
- Знає: ім'я, баланс, поточний велосипед
- Вміє: перевірити, чи вистачає грошей; заплатити



Демо-сценарій:

1. Створити 2 станції.
2. Створити 4 велосипеди і поставити на станції.
3. Створити 2 клієнтів.
4. Провести 3 поїздки.
5. Спробувати взяти велосипед на порожній станції.
6. Показати баланси.
7. Показати звіт.
